# Fluxos UX

## Fluxo A — Atendimento coberto
Home → Solicitar atendimento → Serviço → Localização → Elegibilidade → Autorização → Prestador → Acompanhamento → Concluído.

## Fluxo B — Venda avulsa
Solicitar atendimento → Não elegível → Oferta avulsa → Pagamento → Confirmação → Autorização → Prestador.

## Fluxo C — Contingência
Solicitação → Indisponibilidade → Avaliação de risco → Contingência → Código provisório → Prestador → Auditoria posterior.

## Fluxo D — Inadimplência
Home/Contrato → Cobrança pendente → Regularizar → Pagamento → Contrato normalizado.
