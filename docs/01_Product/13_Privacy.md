# Privacidade e LGPD — Diretrizes para o Protótipo

A CuraNexo lidará potencialmente com dados pessoais e dados pessoais sensíveis relacionados à saúde. Por isso, o protótipo deve demonstrar uma arquitetura conceitual de mínimo acesso.

## Dados
- Identificação.
- Contato.
- Contrato.
- Cobertura.
- Histórico de utilização.
- Dados necessários à autorização.
- Dados financeiros.
- Dados sensíveis de saúde, quando indispensáveis.

## Princípios
- Coletar apenas o necessário.
- Separar dados por domínio.
- Aplicar menor privilégio.
- Registrar acessos e eventos relevantes.
- Evitar exibir dados clínicos em dashboards financeiros.
- Não colocar dados sensíveis em logs de aplicação.

**Pendente:** avaliação jurídica, bases legais, DPO/encarregado, política de retenção, DPIA/RIPD quando aplicável, contratos com operadores e política de resposta a incidentes.
