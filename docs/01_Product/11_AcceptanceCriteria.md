# Critérios de Aceitação do Protótipo

- O OWNER consegue compreender a proposta sem explicação técnica.
- A jornada cliente → solicitação → elegibilidade → autorização é navegável.
- A jornada não elegível → pagamento avulso → autorização é visualizada.
- O backoffice apresenta operação, contratos e financeiro.
- A visão de inadimplência é compreensível.
- O centro de resultados possui visão executiva.
- A contingência aparece como fluxo separado e controlado.
- O prestador é apresentado como categoria/integração, sem dependência visual da CAVOK.
- Nenhuma integração real é necessária para a validação.
