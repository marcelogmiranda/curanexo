# CuraNexo — PRD e Especificação do Protótipo Visual

**Versão:** 0.1.0  
**Status:** Protótipo visual / validação com OWNER  
**Framework mobile:** Flutter / Dart  
**Backoffice:** Web responsivo  
**Backend:** Supabase / PostgreSQL  
**Hosting web:** Vercel  
**Pagamentos:** Stripe  
**Objetivo desta versão:** especificar somente o necessário para gerar um protótipo navegável via Vibe Code.

> **Nome provisório:** CuraNexo. A disponibilidade jurídica e marcária ainda deve ser validada antes de qualquer lançamento comercial.

## Estrutura
- `docs/01_Product/` — visão, PRD, requisitos e regras essenciais.
- `docs/02_Architecture/` — arquitetura necessária para o protótipo e princípios da solução.
- `docs/03_DataModel/` — modelo conceitual mínimo.
- `docs/04_UX_UI/` — design, telas e fluxos do protótipo.
- `docs/15_Appendix/` — decisões, glossário, pendências e prompt para Vibe Code.

As demais áreas do modelo documental de referência permanecem registradas como **pendentes** para a fase de construção real.
